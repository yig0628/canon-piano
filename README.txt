캐논 전곡 양손 숫자 피아노 — 공개 배포용 PWA

구성: index.html, app.js, style.css, score.json, piano-samples, manifest, sw.js
서비스 계정이 없어도 작동하도록 만든 독립형 웹앱입니다.
다만 이 ZIP을 받는 것만으로 공유 웹사이트가 만들어지지는 않습니다.

GitHub Pages 게시 방법:
1. GitHub의 새 공개 저장소를 만들고 ZIP 안 파일을 저장소 최상위 폴더에 업로드
2. Settings > Pages > Deploy from a branch > main / (root) 선택
3. 생성되는 https://계정.github.io/저장소/ 링크를 친구에게 공유
4. Chrome에서 링크 열기 > 메뉴 > 홈 화면에 추가
